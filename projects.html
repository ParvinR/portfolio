Undergraduate Research — Queens College, CUNY

Bayesian Optimization: Dynamic Mobile Observer Coverage

Research project supervised by Prof. Bon Sy. The work addresses the parameter tuning problem for a dynamic mobile observer coverage model — specifically optimizing the parameters K (number of observers), v (velocity), and R (coverage radius) to maximize area coverage efficiency.

The approach applies Gaussian Processes as a surrogate model with Expected Improvement as the acquisition function. Experiments were implemented using scikit-optimize and GPyOpt, with data manipulation and visualization through NumPy, Pandas, and Matplotlib.

Group Project — Machine Learning

Diabetes Predictor

A Java-based diabetes prediction system built as a group project. Implements a custom Random Forest classifier from scratch — including Decision Tree nodes, splitting logic, and ensemble voting — to predict diabetes risk from patient health data with 94% accuracy.

The pipeline includes CSV dataset loading, missing data handling via mean imputation, data normalization, and a full prediction breakdown showing which health features contributed most to the result. Supports custom dataset uploads for model retraining.

Personal Project — Full-Stack Web

Interactive React Multi-AI Tool

A React-based web application that enables structured, multi-round collaboration between Claude (Anthropic) and ChatGPT (OpenAI). Users can chain model responses, compare outputs side-by-side, and manage conversational context across different AI systems in a single interface.

Built with functional React components and hooks, the tool handles API integration, conversation state management, and a clean UI for directing prompts to specific models or routing one model's output as the next model's input.
